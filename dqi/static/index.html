    Walkthrough

    Take a guided tour through the Inspector with example data, or expand a topic below. You can leave the tour at any step.

    Evaluate one response

    Paste a task and apply your rubric
    1. On the upload screen, choose Review one task. Paste the original prompt and the AI’s response. If a score depends on a policy or source passage, expand Reference answer or evidence and paste it there.
    2. Choose Upload rubric. CSV and JSON can hold up to 12 criteria. TXT and Markdown each describe one criterion. Expand a criterion to edit its wording or set its minimum, maximum, and score type.
    3. Choose the review model and click Preview evaluation. When ready, select your key, confirm the use of API credits, and click Run evaluation.

    For example, a customer support response can earn full credit for tone and partial credit for resolution if it leaves out a required confirmation step. Give each criterion its own score definitions.

    Read a score or get a second opinion

    Each criterion shows its score, the reviewer’s explanation, and quotes from the supplied material. Insufficient evidence means the reviewer could not support a score. Check the quotes against the criterion before accepting the judgment.

    For another reading, expand the assessed task or dataset record and select Get a second opinion. Choose a different model and confirm the additional API request. Compare the two explanations to see where the reviewers disagree.

    Inspect a dataset

    Upload a file or try the demo

    Drop the response file onto Upload file or use Choose file. The Inspector accepts CSV, TSV, JSON arrays, JSONL, NDJSON, and their gzip-compressed versions. In Choose checks, expand Preview the first records to confirm the column names and values.

    To learn with an example, choose Load demo data. Its six records include a missing answer, conflicting ratings, and an out-of-range score.

    Match criteria and choose scoring rules

    Start with the appropriate preset under Choose your checks. Under Shared fields, select the columns containing the response, ID, or explanation you want to check. Under Rating attributes, choose the score columns and specify which values are required, numeric, whole, or within a range.

    For a custom rubric, click Choose rubric file. Review each proposed score column and scale, correct any match or skip the criterion, then click Apply rubric. For example, you can match a criterion called tone_score to a column called courtesy_rating.

    Find duplicates, conflicting ratings, and coverage gaps

    Turn on Include audit and pick the question column. Select the checks for repeated question–answer pairs and different ratings on identical pairs. To queue low source scores, set a review threshold for the relevant attribute.

    Under Check category coverage, pick a category column and set a minimum count. Enter expected category names to catch groups with zero rows. Click Run inspection to run the selected checks locally.

    Read findings and decide which records to inspect

    The report opens in Simple view with the outcome and highlights. Select Detailed under Report view to explore the evidence. The saved HTML summary has the same switch.

    Checks by attribute shows which scoring fields have missing or invalid values. Score distributions shows how valid scores are spread across each scale. Under Findings, read the rule, observed value, and reason for each flagged row.

    With Include audit selected, open Records to review and filter by reason, attribute, or both. Use Next and Previous to browse the matches. Expand a record to see the original text, ratings, and suggested next steps.

    Choose Download matching records (CSV) to save every matching record across all pages. Download full review queue saves every flagged record.

    Check whether an existing rating fits the answer

    In Detailed view, open Does the rating fit the answer?. Choose Whole dataset for every eligible answer, or Selected records for up to 20. Choose the criteria and model, then click Estimate review cost to see the scope and estimated API spend locally.

    Review the estimate, choose your API key, check the authorization box, and click Confirm and start review. The model scores each answer independently. The Inspector then compares that score with the original rating. Close means the difference falls within your chosen gap. Questionable marks a larger difference for human review.

    API access and reports

    Save an API key and understand when credits are used

    Open Settings, enter your OpenAI API key, and click Save key to keep it in your Mac’s Keychain. Later reviews select Use saved key automatically. You can replace or remove the key in Settings, or choose a one-time key for a particular review.

    File checks, dataset audits, and previews run locally. Starting an AI evaluation sends the selected prompts, responses, rubrics, and any supplied references to OpenAI and uses API credits. Each second opinion is a separate request.

    Download reports and reopen the Inspector

    In a dataset report, use Download report bundle to keep the full inspection. Open summary.html inside the ZIP for a readable report, or use findings.csv to work through issues row by row.

    AI evaluations have their own Download answer review bundle with HTML, CSV, and JSON. Download the reports you want to keep before closing the local session. On your Mac, Add desktop shortcut gives you a direct way to reopen the app.
